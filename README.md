# Nonstop Boxing – Info-Seite

Statische Seite für nonstop-boxing.de (kein Build, kein Server nötig).

- `index.html`: Startseite
- `impressum.html`, `datenschutz.html`: Pflichtseiten
- `stil.css`, `icon.svg`: Gestaltung

**Hochladen:** Den Inhalt der Datei `nonstop-boxing-info.zip` entpacken und die Dateien in das Hauptverzeichnis der Domain legen (dort muss `index.html` direkt liegen, nicht in einem Unterordner).

**Vorschau lokal:** `python3 -m http.server 8150` in diesem Ordner, dann `http://localhost:8150/`.
